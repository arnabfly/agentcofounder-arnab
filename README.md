# Frame-First Autonomous App Builder

Submission for the Stockholm AI AgentCofounder challenge, built on the official
starter and the Pi coding agent.

[![Demo video](https://img.youtube.com/vi/JeWa5BUpLW0/maxresdefault.jpg)](https://youtu.be/JeWa5BUpLW0)
Demo video: https://youtu.be/JeWa5BUpLW0

The pipeline turns a plain-English product idea into a tested, runnable web
app. The main design decision is to make the LLM configure a pre-built,
domain-neutral application frame instead of generating an application from
scratch. This keeps token usage low and makes the output predictable.

## Quickstart

Requires Node 22.19.x and npm 10.9.x on Linux or macOS. On Windows, use WSL
or GitHub Codespaces.

```bash
npm ci --ignore-scripts
npm --prefix app-template ci --ignore-scripts
export OPENROUTER_API_KEY="..."   # or any provider credential Pi supports
CHALLENGE_PROVIDER=openrouter CHALLENGE_MODEL=qwen/qwen3-coder npm run challenge
```

To run a different idea:

```bash
npm run challenge -- --idea-file ideas/plants.txt
```

After a run, start the generated app with `npm --prefix output/app run dev`
and open http://localhost:3000. The audited result is written to
`result.json`, per-run logs to `artifacts/runs/`.

## How it works

The template in `app-template/` is a complete, hand-written tracker
application: list and detail views, forms with validation, search, filtering,
statistics, sorting, grouping, a bar chart, an optional second linked list, a
step-through review mode, import/export, and localStorage persistence that
survives refresh and corrupted data. None of it references any particular
domain.

For most ideas, the agent only rewrites one file, `src/config.ts`, which
declares the entity, its fields, and which of the frame's capabilities to
switch on. A validator runs as the first test, so an inconsistent config
fails with a precise message rather than a cryptic error.

Test coverage ships with the frame: `src/journeys.dormant.tsx` contains
journey tests for every capability. The agent activates them with a single
rename, and they adapt to whatever the config declares. The report the
challenge requires (`report.partial.json`) is generated by a script from the
actual Vitest results, so reported journeys always reflect tests that really
ran.

When an idea needs a mechanism the config cannot express, for example a live
calculation, a timer, or a random selection, the agent edits `src/custom.tsx`.
That file exists in the template as an empty panel with its wiring already in
place, so implementing such a feature means writing one component and one
test file.

## Measured results

All runs below used the submitted version of the prompt and template, with
qwen3-coder via OpenRouter. Scores use the challenge formula
(input + 3 × output + 0.1 × cache reads); lower is better. For reference, the
unmodified starter scores about 82,700 on the public book idea and finishes
with status `partial`.

| Idea | Approach taken by the agent | Status | Journeys | Score |
|---|---|---|---|---|
| Books (official public idea) | config only | success | 12 | 11,850 |
| Gym workouts | config only | success | 13 | 13,029 |
| Volunteers coordination | config only | success | 14 | 13,758 |
| Plants watering log | config only | success | 13 | 14,003 |
| Lemonade stand sales | config only | success | 13 | 21,094 |
| Shared expenses | config only | success | 14 | 36,722 |
| Swedish flashcards | review mode | success | 12 | 12,779 |
| Focus timer | custom code in the slot | success | 11 | 34,172 |
| Random dinner picker | custom code in the slot | success | 12 | 63,301 |
| Tip splitter | custom code | success | 9 | 78,857 |

The same setup was also verified in GitHub Codespaces, and with other models
and providers: the general model qwen3-32b completes the book and lemonade
ideas at around 36,000, and Berget AI works once Pi's compatibility flags are
set (see below).

## Model provider

Nothing in the repository is tied to a vendor. `CHALLENGE_PROVIDER` and
`CHALLENGE_MODEL` select any provider and model Pi supports. Providers not
built into Pi can be added through `~/.pi/agent/models.json`; for Berget AI,
set `"compat": { "supportsDeveloperRole": false, "supportsReasoningEffort":
false }` in that file, otherwise the model does not receive its context
correctly.

## Repository layout

- `app-template/` — the application frame, copied fresh into each run
- `solution/system-prompt.md` — the agent's instructions
- `ideas/` — the test ideas used for the results above
- `src/`, `test/` — the organizer's runner and verifier, unmodified
- `tools/trace-report.mjs` — prints a readable summary of a run
- `artifacts/runs/` — per-run audit logs

`npm run check` runs the organizer's full test suite and passes.
